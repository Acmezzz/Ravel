# Ravel Desktop UI/UX 设计审查报告

- 日期：2026-08-30
- 范围：对话 / IDE / Histos 三模式主界面、命令面板、资源中心、Trust Center（共 9 张截图）
- 基准目标：Codex 桌面端 / Claude Code 桌面端的极简、扁平、现代、高质感水准
- 审查方式：静态视觉走查（排版 / 布局 / 可用性 / 规范一致性）

---

## 0. 总体诊断

当前界面的骨架（三栏 + 顶栏 + 底部输入）是合理的，问题集中在**视觉系统层面**：

1. **强调色失控** — 品牌橙被同时用于模式切换、Tab、筛选 chip、主按钮、焦点环、警告文字、Logo 容器等 7+ 种角色，导致"处处强调 = 没有强调"，也是"按钮丑"的主要根源。
2. **对比度系统性偏低** — 大量 11–12px 浅灰文字（约 #A3A3A3 级）用于次要信息与空状态，估计对比度 < 3:1，整屏显得"雾蒙蒙"，缺高级感。
3. **组件样式不统一** — 按钮有 4+ 种形态、Tab 有两种激活样式、圆角有 4 档、图标风格混用，缺少一张明确的组件规格表。
4. **信息架构冗余** — 左栏与顶栏模式切换重复、命令面板文案三重重复、多处标题/标签/占位符重复表达。

Codex / Claude Code 桌面端的共性做法（值得对照）：**单一克制的强调色、中性灰白底、顶栏极简（< 8 个元素）、输入区为视觉锚点、空状态克制但可行动、命令面板只有一个输入框**。

## 3. 设计缺陷（可辨识性 / 信息层级 / 配色 / 规范违背）

### 3.1 主界面

| # | 严重度 | 位置 | 问题 | 改进方向 |
|---|--------|------|------|----------|
| D1 | 高 | 顶栏模式切换 | 三个独立按钮形态不一：激活为橙色胶囊、IDE 带橙点、Histos 带橙色菱形图标，视觉重量不一，不像"同一组开关" | 改为标准 segmented control：一个圆角容器内三段，激活段白底+轻投影（浅底方案），未激活透明灰字 |
| D2 | 高 | 输入框 | 左侧 ⌘ 图标是 macOS 修饰键隐喻，**这是 Windows 应用**（截图即 Windows 终端），语义错误 | 改为 "+"（附件/命令入口）或 Windows 风格 Ctrl 语义；回形针保留 |
| D3 | 中 | 左栏会话/活动 Tab | 两种激活样式并存：会话=橙色文字/下划线，活动=橙色填充胶囊 | 统一一种（建议 segmented 小药丸组，中性深底激活） |
| D4 | 中 | 活动子筛选 | 全部/待处理/运行中 三个 chip 挤在面板头部，与 Tab 层级混淆，"待处理"橙色激活过于扎眼 | 激活态改中性深色；或收成下拉 |
| D5 | 中 | 会话面板空态 | "暂无会话，点击「新建」开始" — 但面板上找不到「新建」按钮 | 面板头部加标题"会话"+ 右侧 + 新建按钮；空态文案与按钮呼应 |
| D6 | 中 | 右栏状态 | "连接：就绪" 等重要状态与"暂无权限信息"等空态同为灰字，状态不可扫读 | 状态一律 badge 化：绿点+就绪 / 灰点+未连接 |
| D7 | 中 | 建议 chip | 三个建议项 11px 浅灰 chip，可发现性差，不像可点 | 参考 Claude Code：纵向列表卡（图标+13px 文案），hover 有反馈 |
| D8 | 低 | 欢迎 Logo | ∞ 放在米色圆角方块里，底色与页面米色接近，显"脏" | 去容器底色，或改纯黑/深灰 ∞ 符号，缩小至 32px |
| D9 | 低 | 输入框 | 卡片浮起风（阴影+大圆角）与整体扁平方向不符；发送按钮空输入时似乎可用且色浅 | 1px 边框 + 8px 圆角、聚焦边框加深；发送按钮空输入禁用（40% 透明度） |
| D10 | 低 | 窗口控制 | 最小化/最大化/关闭与自定义图标混排无分组 | 与其他工具图标间加 8px 分隔；关闭 hover 红色（Windows 规范） |

## 5. 设计 Token 建议（落地用）

```
背景:   主 #FFFFFF / 侧栏 #FAFAF9 / 悬浮 #F5F5F4
边框:   #E7E5E4（1px）
文字:   主 #1C1917 / 次 #57534E / 弱 #78716C（仅微文案）
强调:   品牌橙（建议微调至 #D97706 或保持现色），仅 primary 按钮 + 激活态
状态:   成功 #16A34A / 警告 #D97706 / 错误 #DC2626（warning 不再用作正文色）
字号:   11 / 12 / 13 / 15 四级；字重 400 / 500 / 600
控件:   高 28（紧凑）/ 32（标准）px；圆角 6px（控件）/ 10px（容器）
图标:   16px 线性（Lucide 系），1.5px 描边，全库统一
间距:   4 基数网格；常用 8 / 12 / 16 / 24
```

> 注：Codex / Claude Code 桌面端均为 dark-first。若 Ravel 有暗色计划，建议 token 直接按双主题定义（上述色板对应 stone 系浅色，暗色映射 neutral-900 系），避免后期返工。

## 6. 附：值得对标的细节清单

- **Claude Code**：输入区即主页（上下文用量、模型、模式都收在输入框周边）；空态建议为纵向列表而非 chip；顶栏只有项目名与最少图标。
- **Codex 桌面端**：任务列表主导航 + 极干净顶栏；强调色全场仅一处；diff/终端等深色面板与浅色 UI 的边界用 1px 边框而非阴影。
- 两者共同点：**没有任何元素使用"米黄底+橙色"的暖色系组合**——这是当前 Ravel 显"旧"的最大单一因素，建议优先验证换中性色板的整体效果。
