# Ravel upstream and compatibility notes

Ravel is an independent desktop product derived from the Omega desktop work and selected Pi runtime components.

The first Ravel release keeps the Pi runtime package names, `.pi` configuration/session/resource layout, and upstream runtime compatibility contracts so existing sessions and extensions remain usable. These names are compatibility identifiers, not a claim that Ravel owns the upstream work.

When distributing Ravel, retain the repository `LICENSE` and `apps/ravel-desktop/THIRD-PARTY-NOTICES.md`. Upstream Pi packages remain subject to their original copyright and MIT license notices, including Mario Zechner's copyright. Adapted desktop components retain their respective third-party attributions.

Ravel-specific changes are maintained in this repository and are not an endorsement or official release of the upstream Pi project.
